# اتحادنا AI – العقار 110
تطبيق ويب (PWA) لإدارة اتحاد الشاغلين، يُثبَّت على الموبايل ويعمل بدون إنترنت بعد أول فتح.

**الرابط:** https://mhmedzaki3-oss.github.io/etehadna-building-110/

## الاستخدام
- **المدير (واحد فقط):** يدخل بكلمة مرور ينشئها أول مرة، ويسجل الاشتراكات والمصروفات وقيمة الاشتراك واسم المدير وأسماء السكان. بيانات المدير محفوظة على جهازه، فيأخذ «نسخة احتياطية» دورياً.
- **الجيران:** المدير يضغط «🔗 رابط عرض للجيران» ويرسله في مجموعة واتساب. الرابط يعرض آخر بيانات (للقراءة فقط) بدون حساب. وكلما تغيرت البيانات يرسل المدير رابطاً جديداً.
- **التنبيهات:** أي ساكن يرسل مشكلة عبر زر واتساب، والمدير يسجلها في السجل لتظهر للجميع.
- **تغيير المدير كل 3 شهور:** المدير القديم يرسل «نسخة احتياطية»، والجديد يستعيدها على جهازه.

## التثبيت
- **أندرويد (Chrome):** زر «⬇ تثبيت التطبيق» أو قائمة ⋮ ← تثبيت التطبيق.
- **آيفون (Safari):** مشاركة ← إضافة إلى الشاشة الرئيسية.

## تنبيهات
كلمة المرور تقفل الواجهة فقط والبيانات غير مشفرة على الجهاز. رابط العرض يحمل البيانات داخله، فلا يُنشر خارج مجموعة العمارة. ليس اعتماداً محاسبياً أو قانونياً.
